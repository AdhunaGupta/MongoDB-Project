# MongoDB Project - Student Database Management

## About Project
This project demonstrates MongoDB CRUD operations on a Students database with 50 records.

## Queries Included
1. CREATE DATABASE - use Students
2. CREATE COLLECTION - db.createCollection("students")
3. INSERT 50 Students - db.students.insertMany()
4. DISPLAY ALL - db.students.find()
5. $eq - Equal to
6. $gt - Greater than
7. $lt - Less than
8. $gte - Greater than or equal
9. $lte - Less than or equal
10. UPDATE - updateOne
11. DELETE ONE - deleteOne
12. DELETE MANY - deleteMany
13. $and Operator
14. $or Operator
15. SORT - Ascending & Descending
16. LIMIT
17. SEARCH BY CITY
18. COUNT DOCUMENTS

## Tools Used
- MongoDB Compass / MongoDB Shell
